# Integrating `@byteplus-sdk/vod-v1` without an npm registry

This SDK is **not published to npm** — you install it straight from the git repo.
Because it lives in a **pnpm monorepo** and depends on `@byteplus-sdk/core`
(`workspace:*`), a plain `npm install github:owner/repo` does **not** work:

- the repo root is `private` and is not the package you want;
- the built `dist/` is not committed (it is generated by a build);
- the raw manifest keeps the `workspace:*` dependency, which npm rejects with
  `Unsupported URL Type "workspace:"`.

Use one of the methods below instead. **You always need both packages**:
`@byteplus-sdk/core` (the signer/transport) and `@byteplus-sdk/vod-v1`.

---

## Method A — build & install tarballs (recommended, registry-free)

`pnpm pack` rewrites the `workspace:*` dependency to a real version, producing
self-contained tarballs you can install anywhere. Verified end-to-end.

**1. Clone and build the SDK** (once, and after every update):

```sh
git clone git@github.com:longlee218/byteplus-nodejs-sdk-v2.git
cd byteplus-nodejs-sdk-v2
pnpm install
pnpm -r build
```

**2. Pack the two packages** into a folder of your choice:

```sh
mkdir -p ~/byteplus-tgz
pnpm --filter @byteplus-sdk/core   pack --pack-destination ~/byteplus-tgz
pnpm --filter @byteplus-sdk/vod-v1 pack --pack-destination ~/byteplus-tgz
# → ~/byteplus-tgz/byteplus-sdk-core-0.1.0.tgz
# → ~/byteplus-tgz/byteplus-sdk-vod-v1-0.1.0.tgz
```

**3. Install both tarballs in your project** (npm, pnpm, or yarn):

```sh
npm install ~/byteplus-tgz/byteplus-sdk-core-0.1.0.tgz \
            ~/byteplus-tgz/byteplus-sdk-vod-v1-0.1.0.tgz
```

Or pin them in your `package.json` and commit the tarballs (or host them):

```json
{
  "dependencies": {
    "@byteplus-sdk/core": "file:./vendor/byteplus-sdk-core-0.1.0.tgz",
    "@byteplus-sdk/vod-v1": "file:./vendor/byteplus-sdk-vod-v1-0.1.0.tgz"
  }
}
```

> Do **not** use `file:` pointing at the package **source directories** — the raw
> `packages/vod-v1` manifest still has `workspace:*` and npm will reject it. Point
> `file:` at the **packed `.tgz`** (or use Method B).

## Method B — git submodule inside a pnpm workspace

If your project already uses **pnpm workspaces**, add this repo as a submodule and
let pnpm resolve `workspace:*` natively — no packing, and updates are a `git pull`.

**1. Add the submodule:**

```sh
git submodule add git@github.com:longlee218/byteplus-nodejs-sdk-v2.git vendor/byteplus-sdk
git submodule update --init --recursive
```

**2. Include its packages in your `pnpm-workspace.yaml`:**

```yaml
packages:
  - "packages/*"
  - "vendor/byteplus-sdk/packages/*"
```

**3. Depend on it in your app's `package.json`:**

```json
{ "dependencies": { "@byteplus-sdk/vod-v1": "workspace:*" } }
```

**4. Install & build once:**

```sh
pnpm install
pnpm --filter @byteplus-sdk/core --filter @byteplus-sdk/vod-v1 build
```

pnpm links `@byteplus-sdk/vod-v1` (and its `@byteplus-sdk/core` dependency) from
the submodule. Update with `git -C vendor/byteplus-sdk pull && pnpm install`.

---

## Requirements

- **Node.js ≥ 18** (uses global `fetch`).
- **pnpm** (`npm i -g pnpm`) and **git** to build/pack the SDK.
- The SDK is dual **ESM + CJS**, so `import` and `require` both work.

## Usage after install

```ts
import { DefaultCredentialProvider } from "@byteplus-sdk/core";
import { VodV1 } from "@byteplus-sdk/vod-v1";

const vod = new VodV1({
  region: process.env.BYTEPLUS_REGION ?? "ap-singapore-1", // or ap-southeast-1
  credentialProvider: new DefaultCredentialProvider(),      // env / CLI / ECS order
});

const spaces = await vod.space.listSpace({});
```

**Credentials** are read from the environment (never hard-code them):

```sh
export BYTEPLUS_ACCESSKEY=...   # or BYTEPLUS_ACCESS_KEY
export BYTEPLUS_SECRETKEY=...   # or BYTEPLUS_SECRET_KEY
export BYTEPLUS_REGION=ap-singapore-1   # optional
```

See `README.md` for the full API surface (playback, upload, media, workflow,
space, cdn, callback, measure, quality, drm).

## Updating

- **Method A:** re-run `git pull && pnpm -r build`, re-`pnpm pack`, reinstall the
  new `.tgz` (bump the version in `package.json` first if you want a new number).
- **Method B:** `git -C vendor/byteplus-sdk pull && pnpm install`.
